> 版本：1.0.0  
> 整理日期：2026-08-10

> 类型：IP Kit / 角色资产规范，不是活动 Brand Kit

## 1. 定义与边界

心仔 IP Kit 是一套可版本化的角色身份、视觉结构、标准色、比例、表情、动作、源文件与使用规则。

它回答的是：

- 这个角色是谁；
- 哪些结构必须保持不变；
- 哪些表情、动作、服装和道具可以变化；
- 已有哪些正式源文件；
- 在传播、线下装置和周边中使用前要检查什么。

它不管理：

- 某个活动的标题、KV、页面主题色与营销构图；
- 合作品牌与合作 IP 的身份关系；
- H5 / Native / Lynx 页面的模块结构；
- 活动资源位、海报或战报的整套视觉风格。

以上内容应分别进入项目、Brand Kit、页面模板或素材资产，不能反向改写心仔本体。

### 3.1 世界观摘要

心仔会扫描城市烟火与小众目的地，发现隐藏老字号、氛围小店和宝藏民宿；同时携带攻略、团购券与避坑指南，为用户规划吃喝玩乐。

### 3.2 核心能力

1. **烟火雷达眼**：发现好店与目的地，也是情绪变化的主要窗口。
2. **百宝挎包**：收纳攻略、团购券和避坑指南，是角色“有求必应”的业务道具。

## 4. 不可变结构与可配置层

### 4.1 爱心脑袋

- 角色最主要的轮廓识别；
- 爱心外轮廓、左右心瓣关系、头身主比例不可变；
- 只允许随正式动作产生轻微透视、挤压和朝向变化。

### 4.2 烟火雷达眼

- 大眼体块、白色眼眶和黑色瞳孔的基本关系保留；
- 瞳孔、眼皮、眉形可以承载表情变化；
- 星星、蒸汽、感叹号等只作为轻量情绪辅助符号。

### 4.3 云朵腮红

- 两侧云朵形状、成对关系和粉色识别不可变；
- 允许随透视轻微缩放；
- 不得替换成普通圆形腮红或移除。

### 4.4 百宝挎包

- 红色爱心包体、斜挎关系和抖音标识不可变；
- 可随动作摆动角度；
- 即使产生遮挡，也需要保留足够的可识别部分。

### 4.5 圆圆小手

- 保持圆润体块；
- 固定为四根手指；
- 手势、持物和前后关系按正式动作资产变化。

### 4.6 帽子与服装

- 默认草帽、浅蓝上衣、黑短裤是标准造型；
- 服装、帽子和道具可按活动场景变化；
- 变体不得破坏爱心头部、身体比例、挎包与业务归属。

## 5. 标准比例

## 11. 生成与二创质检

规范建议生成新动作时以标准形象作为首图，使用内部生成工作流，并推荐 GPT 2.0。无论采用何种模型，生成结果都不能直接作为正式资产发布。

### 11.1 建议步骤

1. 载入 2D 或 3D 标准形象；
2. 只修改服装与帽子；
3. 再调整动作或环境；
4. 用标准图回查爱心轮廓、比例、挎包和手指；
5. 检查 Logo、title 与授权范围；
6. 人工批准后建立新版本和资产 ID。

### 11.2 发布前检查清单

- [ ] 爱心脑袋外轮廓未被改写
- [ ] 云朵腮红仍为成对云朵形
- [ ] 百宝挎包形状、斜挎关系与标识正确
- [ ] 手指数量为四根，没有拟真人手
- [ ] 头 / 身 / 腿比例没有拉长
- [ ] Heart Red 与服装主色未发生非授权漂移
- [ ] 帽子、挎包和身体连接处没有生成变形
- [ ] 正式署名、Logo 与传播授权已确认
- [ ] 没有误用受版权限制的应用示意图
