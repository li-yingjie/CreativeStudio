# 创意工坊三类产物编辑器产品规格

> 状态：Demo P0 实施基线
> 更新时间：2026-08-17
> 需求来源：飞书需求文档 `MPJhd2lOwofBHbxdzepcSB7Qnqe` revision 3885（只读核对）
> 适用范围：项目工作区中的 H5 页面、Lynx 页面与分层图片；Markdown 文档和玩法配置仍使用各自编辑器。

## 1. 目标与边界

项目工作区固定为三泳道：左侧 Chat、中间画布、右侧编辑器。用户从对话中的产物卡、项目树或画布对象进入同一份项目草稿；Chat、画布和编辑器不是三份数据。

编辑器的目标不是替代 Figma、VS Code 或完整图像软件，而是让运营与设计协作者在不破坏交付约束的前提下完成高频修改：

1. 看清当前编辑的是哪个产物、页面、组件或图层。
2. 精确修改开放字段，并在画布中实时看到结果。
3. 用自然语言或画笔做受控生成式修改。
4. 保护人工接管字段、品牌固定件、玩法事实和不可变像素。
5. 保存草稿、形成版本、校验并导出可交付产物。

P0 不做：任意 React/DSL 生成、通用代码 IDE、从空白搭建完整 Lynx/H5 工程、从空白制作图层模板、绕过权限直接修改已发布版本。

## 2. 统一编辑模型

### 2.1 三泳道职责

| 区域 | 用户任务 | 主要对象 | 产生的修改 |
| --- | --- | --- | --- |
| Chat | 描述目标、补充约束、确认方案、批量修改 | 当前项目、当前产物、引用资产 | 受校验的语义修改批次 |
| 画布 | 浏览全部产物、选择对象、直接操作、试玩、AI 修改 | 页面实例、组件、图层、画笔选区 | 选择状态、直接操作或受控语义 Patch |
| 编辑器 | 查看对象属性、修改确定性字段、校验、保存 | 当前选择对象 | 人工精确修改与草稿版本 |

### 2.2 统一对象层级

| 层级 | 页面类对象 | 图片类对象 | 说明 |
| --- | --- | --- | --- |
| 产物 | H5/Lynx 页面实例 | 图片文档 | 有独立版本、画布尺寸、来源和交付状态 |
| 结构 | 页面、区域、容器 | 图层组 | 决定组织、顺序、显隐与约束 |
| 元素 | 组件、文案、媒体、动作 | 文字/栅格/矢量/形状图层 | 用户主要精确编辑对象 |
| 绑定 | 路由、事件、玩法、数据 | 模板槽位、素材引用、Style/Brand 规则 | 连接运行或交付规则 |
| 选区 | 页面批注锚点 | 画笔矩形/蒙版 | 生成式修改的显式作用范围 |

图片类对象有一条硬边界：只有 manifest 中存在两层及以上真实图层时，才进入“图层/元素”编辑模型。普通 PNG/JPG/WebP 扁平图只有一个“整图”对象，不根据像素内容臆造标题、人物、Logo 或按钮等内部元素；用户主动执行“智能分层”并确认候选后，才切换为多图层文档。

### 2.3 共同能力

- 画布与对象树双向选择；Esc 清空选择。
- 仅当前对象显示属性，未选择时给出可选对象列表。
- 撤销、重做、恢复当前模板版本。
- 自动保存 UI 选择状态；影响产物的值必须进入草稿版本。
- Comment/自然语言修改是画布级 AI 工具，生成可预览的 Patch，不进入右侧精确编辑器，也不直接覆盖已发布版本。
- 人工改过的字段进入“人工接管”；后续 Agent 修改默认跳过并显示差异。
- 保存前执行字段、权限、布局、端能力和引用完整性校验。
- 已发布版本只读；修改必须从发布版本派生新草稿。

## 3. H5 页面编辑器

### 3.1 编辑对象

1. **页面实例**：一个可独立运行、编辑和发布的 H5 页面。
2. **页面区域**：Hero、导航、内容、任务/回流、页尾等语义区块。
3. **布局容器**：纵向流、横向列表、栅格、定位容器、弹层容器。
4. **业务组件**：榜单、卡池、任务、节目单、作品卡、分享卡、规则弹层等。
5. **内容元素**：标题、副标题、按钮文案、图片、视频、图标、标签。
6. **交互动作**：页面跳转、锚点、弹层、提交、分享、返回、刷新。
7. **玩法绑定**：任务、抽奖、集卡、榜单、投票等已登记玩法实例。
8. **数据状态**：加载、空、失败、未登录、资格不足、已完成等展示状态。

### 3.2 编辑分类与字段

#### A. 内容

- 主标题、副标题、说明、按钮文案、标签文案。
- 图片/视频引用、替代文本、封面、焦点位置。
- 文案长度、安全词、换行与截断校验。
- 内容来源：项目输入、Brand/IP Skill、知识库或人工输入。

#### B. 组件

- 区域/组件选择、显隐、复制、删除、锁定和层级。
- 容器宽高、内外边距、间距、对齐、排列、定位。
- 组件变体、尺寸、主题 Token、圆角、背景、字色。
- 手机预览宽度和响应式断点；不得只在单一宽度看起来正确。
- P0 Demo 对开放组件支持移动、复制、显隐和顺序；复杂布局仍受模板约束。

#### C. 交互与运行

- 页面路径、外链、锚点、返回目标和分享入口。
- 点击、曝光、提交、打开弹层、关闭弹层等动作。
- 玩法实例绑定、任务/分享开关、每日上限等页面级参数。
- 加载、空、失败、完成与恢复路径。
- 发布前检查可访问性、浏览器后退、刷新恢复和异常状态。

#### D. 画布 AI 修改（不属于右侧精确编辑器）

- 对当前页面、选中区域或选中组件输入修改要求。
- 显示将修改的对象和字段，不允许“全页悄悄重做”。
- 预览差异后应用；人工接管字段默认跳过。
- 支持“隐藏任务区”“按钮更明确”“标题更有节日感”等语义修改。

### 3.3 H5 专属约束

- 使用 DOM/组件树和受控样式字段；高级 CSS 只对具备权限的专业模式开放。
- 支持 360–430px 移动端宽度及约定断点，长页高度由内容自然撑开。
- 页面画布只展示可操作的浏览器运行态，不提供“设计稿”切换或设计稿下载入口；设计源仅作为项目证据在其他对象中追溯。
- 修改玩法字段必须写回项目玩法事实源，不在页面组件内维护第二份配置。

## 4. Lynx 页面编辑器

### 4.1 编辑对象

1. **Lynx 页面实例**：由 bundle/channel/route 标识的端内页面。
2. **端容器**：状态栏、DuxTitleBar、安全区、滚动容器和端内弹层。
3. **业务组件**：平台登记的 Lynx/Dux 组件及活动业务组件。
4. **内容元素**：文案、图片、视频、图标、标签与组件槽位。
5. **端内动作**：返回、分享、登录、跳转、打开直播/话题/作品等 Bridge 动作。
6. **玩法与数据绑定**：玩法实例、端能力、登录态、用户资格和服务数据。
7. **状态变体**：不同端版本、登录状态、权限状态、阶段和玩法状态。

### 4.2 编辑分类与字段

#### A. 内容

- 与 H5 一致的高频文案和媒体槽位。
- 组件允许的内容 schema、长度、枚举和本地化字段。
- 不允许通过自由 HTML 覆盖端组件结构。

#### B. 组件

- 选择已登记的 Lynx/Dux/业务组件，修改开放 props、槽位、显隐与顺序。
- 页面区域仍按 Hero、导航、内容、任务/回流、页尾组织。
- 组件不兼容当前端版本时显示禁用原因，不提供无效开关。

#### C. 端容器与交互

- bundle/channel/route（P0 允许查看与草稿修改，发布时强校验）。
- DuxTitleBar：标准、透明、隐藏；标题、返回和分享动作。
- 顶部/底部安全区、状态栏前景色、页面背景与滚动行为。
- 返回策略：关闭容器、返回上页或跳转指定业务目标。
- Bridge 动作、入参、失败回退和最低端版本。
- 玩法实例、任务/分享开关、每日上限等运行参数。

#### D. 画布 AI 修改（不属于右侧精确编辑器）

- 只能修改 schema 开放的 props、顺序和绑定。
- 不生成任意 Lynx 代码，不绕过端能力、权限或组件版本限制。
- 修改前说明影响页面、组件、端版本与玩法绑定。

### 4.3 Lynx 专属约束

- H5 与 Lynx 可以共用编辑器壳和基础控件，不能共用任意 CSS/DOM 字段。
- 安全区、DuxTitleBar、返回/分享 Bridge 和最低端版本是 Lynx 发布门禁。
- 端服务未接入时必须显示“待接入/待确认”，不能用 Toast 冒充成功。
- 运行态和 bundle 版本必须可追溯到同一页面草稿；页面画布只保留运行预览。

## 5. 分层图片编辑器

### 5.1 编辑对象

1. **图片文档**：画布、版本、模板、Style/Brand 引用、来源和交付尺寸。
2. **图层组**：主视觉、内容信息、指标、运营动作、Logo、交付信息等语义分组。
3. **文字图层**：真文字、字体、字号、字重、行高、字距、颜色和对齐。
4. **栅格图层**：生成图、照片、证据图片、纹理和复杂合成底图。
5. **矢量/形状图层**：Logo、图标、色块、蒙版和固定装饰。
6. **素材槽位**：IP、Logo、商品、二维码、背景、前景和可替换资源。
7. **生成选区**：画笔/矩形选区及其命中的开放图层。

### 5.2 编辑分类与字段

#### A. 图层与属性

- 图层树、分组、选择、显隐、锁定、层级统一放在右侧编辑栏；画布左侧不再常驻图层栏。
- 位置 X/Y、尺寸 W/H、不透明度；只有模板允许的图层可变换。
- 文字内容、字体、字号、字重、行高、字距、颜色、对齐和换行规则。
- 栅格/矢量素材引用、裁切/焦点、替换来源与授权状态。
- P0 不开放任意旋转、混合模式和像素级自由擦除；这些能力进入专业模式评审。

#### B. 画布 AI 生成编辑（入口轻量化，不混入属性分类）

- 图片卡片直接进入编辑器；编辑器头部只保留 **智能分层 / 智能画笔 / 评论** 三个入口。
- **评论编辑**：点击画面放置编号标记，右侧完成输入、解决和重新打开。
- **智能画笔**：在画面拖动涂抹选区，右侧输入局部修改指令并生成候选。
- 显示将修改的图层、锁定层和保护区；未命中开放对象时阻断。
- 生成结果先作为候选版本，不直接覆盖当前已保存版本。
- 素材工作面不再显示底部通用对话框；项目级自然语言修改统一回到左侧会话。

#### C. 交付规范

- 原始画布与派生尺寸、像素密度、色彩空间和文件格式。
- 标题容量、安全区、Logo 规则、二维码可扫性、锐度和透明背景。
- PNG/JPG/WebP 等扁平成片与图层 sidecar 同时校验。
- 保存与导出前执行锁定层、保护像素和引用完整性校验。

### 5.3 权限与保护

| 权限 | 行为 |
| --- | --- |
| 可编辑 | 可修改声明字段，可被 AI Patch 命中 |
| 受约束 | 只能在模板允许的范围内修改，例如字号阶梯或安全区内移动 |
| 受保护 | 可查看来源和规格，不渲染修改/删除按钮 |
| 外部参考 | 只读，不可编译进正式交付 |

品牌 Logo、二维码、证据图片、复杂主视觉和未授权 IP 默认受保护。多层合成必须定义可写区域与不可变区域，并对保护像素执行合成前后不变量校验。

## 6. 编辑器界面规范

### 6.1 右栏固定结构

1. **上下文头**：产物类型、页面/图片名称、当前对象面包屑、草稿状态、重置。
2. **分类切换**：页面右栏只含“属性 / 图层 / 页面”；点击画布真实节点时自动进入对应对象属性。图片右栏在同一栏内按“图层列表 → 当前图层属性 → 交付依据”纵向组织；单层图片则显示“图片对象 → 整图属性”。
3. **对象属性区**：只展示当前对象适用字段；禁用项必须说明原因。
4. **校验与风险**：就地提示，不在页面顶部堆一张通用检查大卡。
5. **保存动作**：保存当前草稿；导出、发布是独立动作。

画布工具栏另设“AI 修改”。打开后以浮层承载作用对象、Comment/画笔模式、修改要求、差异和应用动作；它不伪装成对象属性 Tab。

### 6.2 选择与反馈

- 画布、对象树与编辑器高亮必须同步。
- H5/Lynx 选择结构化 DOM/组件节点，保留响应式流式布局；只有模板声明为定位元素的对象才允许自由拖拽。
- 多图层图片可直接选择和拖拽未锁定图层；单层图片只能选择整图，不出现伪造的内部元素框。
- 点击可编辑对象打开正确类型的编辑器；点击空白清空选择但不关闭编辑器。
- 只读对象明显置灰且不显示修改按钮。
- 修改实时预览；保存、失败、阻断使用明确 Toast。
- 切换页面或图片时保留各自产物草稿，不串状态。

## 7. 数据、版本与修改协议

- 页面运行结果由同一项目 revision 派生；编辑器不是第二事实源。
- 人工修改、Chat 修改、Comment 修改和画笔修改都归一为可追踪 Patch。
- Patch 至少记录：目标产物、目标对象、字段路径、旧值、新值、操作者、基础 revision 和来源。
- 过期 revision 整批拒绝；命中人工接管字段时逐项跳过并展示差异。
- 保存先写草稿 revision，再触发局部编译与校验；发布只消费校验通过的不可变版本。

## 8. P0 验收清单

### 8.1 H5

- 从项目名进入页面画布，选择 H5 页面后右侧显示 H5 编辑器。
- 修改标题、副标题、CTA，运行态立即变化。
- 切换 Hero/导航/内容/页尾显隐，运行态对应区域变化。
- 调整预览宽度，360–430px 无横向溢出。
- 修改任务、分享和每日上限，玩法运行态变化。
- 页面画布只出现“页面预览”，不存在“设计稿”模式或设计稿下载入口。
- 画布 AI 修改只影响当前页面草稿；右侧精确编辑器没有“批注/AI”Tab；保存、重置、切页不串状态。

### 8.2 Lynx

- 选择 Lynx 页面后右侧明确显示 Lynx，而不是通用 H5 面板。
- 可查看/编辑 route、TitleBar、安全区、返回策略和端组件开放字段。
- 修改文案、区域显隐、任务/分享参数，运行态立即变化。
- 隐藏 TitleBar 后运行态同步；无效 Bridge/未接服务明确显示待接入。
- 页面画布只出现 Lynx 运行预览，不出现设计稿切换。
- 保存、重置、切页不串状态。

### 8.3 分层图片

- 图层列表位于右侧编辑栏并与画布双向选择；画布左侧不再占一条图层轨道；受保护层不可修改。
- 扁平单层图片的右栏只出现“整图”，画布点击始终选择整图；智能分层前不存在任何标题/人物/按钮等内部对象。
- 开放文字图层可编辑内容、字号、颜色、位置、尺寸、不透明度和层级。
- 单图只显示“单图层”且没有“编辑图层”；多图层才显示层数和编辑入口。
- 智能分层、智能画笔、评论从画布头部工具打开；工具激活后在右侧出现与当前任务对应的操作面板。
- 素材库不重复提供通用对话输入；局部修改文案只属于画笔选区上下文。
- 撤销、重做、恢复模板、保存后刷新恢复均有效。
- 原尺寸 PNG 与图层 JSON 可导出；保护层被改写时保存/导出被阻断。
