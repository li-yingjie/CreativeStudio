# 家居焕新 H5 Benchmark 反推规范

更新日期：2026-09-07

## 母板目标

先复刻参考图最左侧暖黄色「双11家居焕新指南」，稳定其视觉系统与内容容器，再接收新的业务 query。当前路由为 `/h5-reference-lab`，此阶段不承载 Young 声音藏品业务。

## 页面骨架

1. 轻量媒体导航：返回、联合媒体标识、分享。
2. 居中宋体主题标题、小字副标、透明底 3D 品类主视觉；主视觉直接悬浮在页面底色上，不允许出现白色矩形画布。
3. 横向牌匾式活动介绍卡：顶部两级台阶缺口、双金线与下半部浅金织纹。
4. 左侧渐隐金山、中央宋体标题与右侧回环细线组成统一段落标题族；卡内标题和独立段落标题只改变尺寸与留白，不改变视觉语法。
5. 带吊钩的投稿方向主卡：中央拱顶、左右阶梯肩、标题、双方向切换、说明、视觉与行动区。
6. 独立的奖励牌匾：短边耳位、双挂点和两个同权奖励单元，不复用投稿主卡轮廓。
7. 白色内容容器中的两列四宫格作品流。
8. 高饱和暖橙胶囊 CTA、媒体品牌和合作伙伴区。

## Design tokens

- 页面底色：纵向三段渐变——首屏暖黄、信息区暖白、转化与合作伙伴区淡黄；用长距离渐变和局部径向光晕衔接，不使用横向分割线。
- 正文色：暖棕 `#70413B`，辅助文字 `#9B7166`。
- 装饰线：金棕 `#DDB67B`，线宽约 1px，双线间距 4–6px。
- 行动色：暖橙 `#FFAE4C`。
- 展示字体：Songti SC / STSong / SimSun，承担页面标题与段落标题。
- 正文字体：PingFang SC / Hiragino Sans GB，承担说明、标签和按钮。
- 圆角：内容小卡 7–14px；主按钮 24px；三类大卡不使用同一个普通圆角矩形，而各自使用语义明确的可伸缩 SVG 轮廓。

## 关键形态合约

- 头图：视觉重心落在下半部；只保留一张白色云朵沙发、一条芥末黄披毯、矮台与画作，后方由半透明橙色曲面和细金线构成空间。主视觉必须交付真实 alpha PNG，浏览器不得用 `mix-blend-mode`、遮罩或白色容器伪造透明；大号「居」只作低对比背景字，不承担业务信息。
- 模块标题：左侧山形不得退化成三角图标，使用至少两层不同透明度的连续山势；右侧至少包含三条长短不同的横线与一处回环。标题、山势、线条共享同一垂直中线，文字始终是最高对比层。
- 活动介绍牌匾：宽扁比例，顶边左右各有一组阶梯缺口；外金线与内白线形成约 5px 间距；底部 48% 叠加低对比织纹与金色晕染。
- 投稿方向主卡：顶边中央抬高形成拱顶，两侧经两级台阶回落；吊钩穿入中轴。标题、切换、正文、行动区依序进入正常文档流，装饰不得遮字。
- 奖励牌匾：使用独立的矩形耳位轮廓与左右挂点，视觉上比投稿卡更矮、更稳定。
- 方向按钮：不是普通圆角按钮，而是低矮八边折面票签；选中态为暖黄纸面、双层细描边、左侧折面与低对比山形水印，未选中态为半透明白纸并主动降低文字和边框对比。
- 主 CTA：只在页面末尾出现，采用宽而扁的暖橙胶囊；不与方向票签复用形态。

## 视觉职责边界

- 3D 家居陈设属于透明位图资产，不用 CSS 或手写 SVG 假造；页面背景色、标题、副标与交互仍由代码拥有。
- 三套卡片轮廓、吊钩、分隔线和票签按钮属于代码原生 SVG 几何，并按各自语义分开维护。
- 所有业务文字使用 HTML，并由内容撑高；位图中不生成业务标题和规则。
- 内容缩略图使用真实图片；播放、时长、作者和标题为独立 DOM。

## 稳定性规则

- 430px 为设计基准，页面宽度使用 `min(100%, 430px)`；370px 以下单独收紧内容列。
- 主内容不使用绝对坐标堆叠；绝对定位只用于不影响排版的装饰与 Hero 图片。
- 卡片 SVG 使用 `preserveAspectRatio="none"` 随对应容器伸缩，文字层保留独立 padding；不得为了贴图形而绝对定位正文。
- 图层顺序固定为底纸/织纹 → 双线轮廓 → HTML 内容 → 吊钩等小装饰；装饰层不得覆盖文案。
- 所有 CTA 使用原生 button，并保留键盘、触屏和无障碍标签。
- 新业务映射时只能改内容数据、主题 token 与主视觉资产，不重写页面骨架。

## 长页节奏与验收矩阵

- 设计基准 430px 下，完整内容链路保持约 2100–2300px：Hero 与介绍约占前 25%，投稿主卡与奖励约占中段 40%，内容流、CTA 与合作伙伴约占后段 35%。不得为“塞进一屏”压缩卡片或图片。
- 内容流缩略图保持竖向信息密度，图片、标题、作者三层齐全；两行内容之间保留明显呼吸区，不缩成后台列表。
- 转化区从暖白缓慢过渡为淡黄，CTA 前后都有留白，合作伙伴区保留品牌信息所需的收尾高度；页面末端由真实内容和 28px 安全底距决定，不用 `100dvh` 制造大块空白。
- 视觉检查逐项记录：Hero alpha 是否真实、模块标题左右装饰是否齐全、三类卡片轮廓是否各自成立、方向票签是否有折面、正文是否被装饰遮挡、横向是否溢出、背景是否连续、CTA 和方向切换是否可点击。
