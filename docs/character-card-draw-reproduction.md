# 角色灵感抽卡复刻记录

参考：[Design Radar 抽取卡牌案例](https://design-radar-team.sierrasuly.chatgpt.site/share/615bf5e3084c47999353e08b3b914842)及其[交互视频](https://design-radar-team.sierrasuly.chatgpt.site/api/assets/cases/69fbd92f0000000035026b5e/video-08.mp4?workspace_key=4d9be0883bc6160281a626e9)。规范：[抖音兴趣卡创作规范](https://bytedance.larkoffice.com/wiki/BHs7w5rT8i6PVgkffO2czHN4nld)。本地路由：`/character-card-draw`。

| 模块 | 尺寸与顺序 | 视觉语言 | 交互 | 背景与边界 |
| --- | --- | --- | --- | --- |
| 首屏头部 | 独立 H5 画布，左上角 6 字标题 | 分层灰蓝渐变、银色文字、低对比度仪式圆盘与几何暗纹 | 无 | 只保留「角色灵感抽卡」，不包含状态栏、频道栏或手机外壳 |
| 抽卡内容区 | 圆角描边容器；提示、细线纹章、七张扇形卡背 | 双层细框、几何星纹、双条浅蓝流线；牌堆从左侧向右铺开 | 手势进度驱动每张牌的位置与转角，滑动完成后可选牌；点击牌背后只有所选牌抬起并放大 | 深蓝遮罩压住背景线纹，容器边框完整 |
| 结果与底部行动 | 原容器内展示翻面卡牌、角色名、创作线索及再抽入口；底部平台行动 | 原创角色插画、浅象牙色行动按钮 | 卡背绕纵轴翻面揭晓，之后点击卡牌可重复翻面；卡内可再抽，「前往活动」进入卡册 | 底部行动始终与内容区隔开 |
| 卡册 | 同主题角色肖像网格与抽中角色的描述 | 延续灰蓝、银边、象牙行动色 | 返回或继续抽卡 | 独立滚动，沿用手机底色 |

| 元素 | 实现边界 | 原因 |
| --- | --- | --- |
| 标题、说明、按钮、结果和卡册 | HTML/CSS | 准确文案、可访问性与真实状态 |
| 页面背景 | 2.7KB 原创 SVG 与 CSS 渐变 | 顶部圆盘、三角结构、中央光晕和底部圆弧分层呈现；透明度控制在不干扰正文与牌面的范围 |
| 卡背装饰 | 4.1KB 原创 SVG | 参考截图中的白色边框、流线、星光与几何纹样，放大仍清晰；不使用截图本身 |
| 牌阵、细纹背景 | HTML/CSS | 每张牌随手势进度独立移动、旋转，可响应布局 |
| 四位角色肖像 | imagegen 原创插画，裁成 512px WebP | 人物质感难以用 CSS 保真；不用参考页真人照片或未授权角色图 |

逐帧观察：1.37 秒牌堆仍在手机左侧；2.42 秒牌背向右错位并逐张转角；3.44 秒形成扇形牌阵；5.35 秒只有被选中的牌垂直抬起；6.44 秒大牌背占据画面中心；7.45 秒纵轴翻到侧边。页面中未展开的牌也以每张 6px 的错位和轻微转角露出纸牌边缘；首个横向手势实时驱动七张牌的独立位置与角度，松手后弹性归位；牌阵展开后横向手势改为选牌焦点。点击已展开的卡牌后约 520ms 放大牌背、1550ms 开始翻面、2350ms 完成揭晓；牌背在翻面前停留约 1 秒。收藏只写入一次，揭晓后可回翻；纵向手势仍由页面处理。减少动画偏好下直接短时揭晓。

规范约束：兴趣卡标题为「角色灵感抽卡」（6 字），卡内不重复标题；核心动作是选牌，单步得到角色结果；底部行动「前往活动」（4 字）进入同主题卡册；没有登录、长按、外部引流、交易或算命内容。首屏文字使用至少 12px。四张肖像尺寸 512×512px，大小 43–62KB；图标 `icon-v1.png` 为 200×200px，约 2KB。

页面已移除状态栏、「关注 / 推荐 / 搜索」、上滑提示、Home Indicator 和手机外框，浏览器标题也独立设置为「角色灵感抽卡」。375px 窄屏牌阵中七张牌都在自定义区域描边内，最外侧牌与操作提示的垂直距离约 14px；390px 高屏的最外侧横向边界为 `x=26–364`，位于内容描边 `x=16–374` 内。短屏大牌背约 315px 高，顶部与卡内标题相隔 12px，底部提示仍在容器内。展开前向右拖动牌堆只铺牌，不触发抽取；展开后向左拖动让焦点移到第 6 张，七牌仍铺开。点击焦点牌后经历抬起、放大和翻面，揭晓后可回翻、再抽，卡册收集计数只增加一次。内容区使用 `overflow: clip`，避免点击卡牌后浏览器自动滚动描边容器。

验证：`npm run lint`、`npm test`、`npm run build` 和浏览器的牌堆、展开、选牌、放大卡背、翻面、回翻、再抽与卡册交互已通过。TinyPNG 脚本因本地没有 `TINYPNG_API_KEY` 未执行压缩；所有新位图已用 WebP/优化 PNG 输出并低于 62KB，新卡背为 4.1KB SVG。
