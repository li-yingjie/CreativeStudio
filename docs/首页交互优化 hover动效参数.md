# 智能创作与作品发布 Hover 动效参数

> 适用范围：创作者中心首页「智能创作」与「作品发布」入口卡。  
> 参数基线：线上 `main`，组件 `EntryCard` / `CardImageIcon`。  
> 实现参考：React + Framer Motion；其他技术栈可按本文参数等效实现。

## 1. 动效目标

- 鼠标进入入口卡后，通过卡片阴影、前后素材卡轻微分层、局部高光与矩阵点闪烁，建立可点击反馈。
- 动效以“克制、轻量、有空间感”为准，不改变标题和描述文字颜色，不做整卡上浮或放大。
- 鼠标离开时快速、自然回到静止态；键盘聚焦与鼠标 Hover 保持一致。

## 2. 触发与状态

| 状态 | 触发条件 | 说明 |
| --- | --- | --- |
| `rest` | 默认、鼠标移出 | 所有素材回到基础位置，动态光效隐藏 |
| `spread` | `hover`、键盘 `focus` | 卡片阴影增强，前后卡展开，光效出现 |
| `tap` | 鼠标按下 / 触控按下 | 整卡缩放至 `0.99` |

- Hover 热区：整张入口卡，尺寸 `100% × 75px`。
- 卡片圆角：`16px`；边框：`0.5px solid rgba(0,0,0,0.05)`。
- 指针在卡内移动时，素材卡产生极轻微的反向视差；移出时视差归零。

## 3. 整卡反馈

| 参数 | Rest | Hover / Focus | 过渡 |
| --- | --- | --- | --- |
| 边框 | `rgba(0,0,0,0.05)` | `rgba(0,0,0,0.07)` | `200ms` |
| 阴影 | `0 5px 8px rgba(0,0,0,0.05)` | `0 10px 24px rgba(28,38,64,0.11)` | `200ms` |
| 整卡位移 | `0` | `0` | 不做上浮 |
| 整卡缩放 | `1` | `1` | Hover 不缩放 |
| Tap 缩放 | — | `0.99` | `70ms`，`ease-out` |

## 4. 素材卡分层动效

### 4.1 基础几何

| 图层 | 尺寸 | 初始位置 | 固有造型 |
| --- | --- | --- | --- |
| 前卡 | `60 × 75px` | `left: 0; top: 5.1px` | 圆角 `12.5px` |
| 后卡 | `60 × 75px` | `left: 17.94px; top: 0` | 内层固定 `rotate(10deg) skewX(-1.54deg)`，圆角 `12px` |
| 图标容器 | `77 × 84px` | 相对入口卡 `left: -1px; top: -5.1px` | 溢出可见 |

### 4.2 Hover 目标值

| 图层 | Rest | Hover / Focus |
| --- | --- | --- |
| 后卡外层 | `x: 0; y: 0; rotate: 0deg` | `x: 2px; y: 0; rotate: 3.5deg` |
| 后卡阴影 | 无 | `drop-shadow(0 5px 8px rgba(42,48,68,0.08))` |
| 前卡素材 | `scale: 0.25; rotate: 0deg` | `scale: 0.26; rotate: -1.4deg` |
| 前卡可视容器 | `scale: 1; rotate: 0deg` | `scale: 1.04; rotate: -1.4deg` |
| 前卡阴影 | 无 | `0 7px 9px rgba(35,42,61,0.14)` |
| 图标底部色光 | `opacity: 0; scale: 0.78` | `opacity: 0.13; scale: 1` |

> 前卡使用 4× 素材：源图渲染尺寸 `240 × 300px`，通过 `scale: 0.25 → 0.26` 实现等效的 `1 → 1.04` 放大，避免低分辨率二次缩放。

### 4.3 进入 / 离开曲线

| 阶段 | 类型 | 参数 |
| --- | --- | --- |
| Hover 进入 | Spring | `stiffness: 380; damping: 28; mass: 0.55` |
| Hover 离开 | Spring | `stiffness: 430; damping: 32; mass: 0.5` |
| 指针视差 | Tween | `100ms; ease-out` |

离开参数略硬于进入参数，用于快速收拢卡面，避免鼠标连续扫过多个入口时产生拖沓感。

## 5. 指针跟随视差

将卡内指针位置归一化到 `[-1, 1]`：

```text
normalizedX = (pointerX / cardWidth  - 0.5) × 2
normalizedY = (pointerY / cardHeight - 0.5) × 2
```

| 图层 | X 位移 | Y 位移 |
| --- | --- | --- |
| 后卡 | `normalizedX × 0.8px` | `normalizedY × 0.35px` |
| 前卡 | `normalizedX × -0.55px` | `normalizedY × -0.4px` |

- 前后卡方向相反，形成轻微景深感。
- 鼠标移出时四个偏移值立即回到 `0px`，由 `100ms ease-out` 完成视觉回正。

## 6. 前卡白色高光

- 形状：`radial-gradient(46px 104px)`。
- 渐变中心：`var(--shine-x) 38%`；整体额外 `rotate(16deg) scale(1.2)`。
- 色阶：`#fff 0% → rgba(255,255,255,0.26) 42% → transparent 76%`。
- Rest：`opacity: 0`，退出 `120ms`。
- Hover：`opacity: 0.35`，进入 `180ms`。
- 水平跟随范围：`-20% ～ 120%`。
- 映射公式：`shineX = clamp(-20, 120, -20 + pointerX / cardWidth × 140)%`。

## 7. 背景矩阵点

| 参数 | 数值 |
| --- | --- |
| 网格 | `48列 × 10行`，共 `480` 点 |
| 点尺寸 | `2 × 2px`，圆形 |
| 点间距 | `7.5px` |
| 点颜色 | `#CED9E3` |
| 默认透明度 | `0.1` |
| 显示遮罩 | 跟随鼠标的 `112px` 径向圆形遮罩 |
| 遮罩色阶 | `black 0% → rgba(0,0,0,0.72) 52% → transparent 84%` |
| 遮罩跟随 | Spring：`stiffness 270; damping 28; mass 0.45` |
| 整层进入 | 延迟 `40ms`，时长 `200ms`，`opacity 0 → 1` |
| 整层退出 | `120ms`，`opacity 1 → 0` |

单点闪烁关键帧：

```text
0% / 100%: opacity 0.10
32%:        opacity 0.52
58%:        opacity 0.19
76%:        opacity 0.38
```

- 单点周期按点位离散分布在 `0.9s ～ 2.7s`。
- 单点使用负延迟错峰，范围约 `0 ～ -3.0s`。
- 缓动：`ease-in-out`，无限循环；仅 Hover / Focus 时播放。

## 8. 智能创作与作品发布的差异

两组入口共用以上所有核心参数，差异如下：

| 项目 | 智能创作 | 作品发布 |
| --- | --- | --- |
| 描述后箭头 | 有 | 无 |
| 箭头 Rest | `x: -3px; opacity: 0` | — |
| 箭头 Hover | `x: 0; opacity: 1` | — |
| 箭头进入 | 延迟 `60ms`，时长 `180ms`，`cubic-bezier(0.22,1,0.36,1)` | — |
| 箭头退出 | `120ms ease-out` | — |
| 后卡素材 | 按入口配置图片或浅灰底板 | 统一浅灰底板 |

入口色光色值：

| 智能创作入口 | 色值 | 作品发布入口 | 色值 |
| --- | --- | --- | --- |
| AI 分身 | `#3478D4` | 发布视频 | `#E54867` |
| 百科 | `#6157D9` | 发布图文 | `#258AF4` |
| 随变 | `#C58A00` | 发布全景视频 | `#6952E8` |
| AI 工坊 | `#D76026` | 发布文章 | `#C58A00` |

## 9. 无障碍与降级

- 键盘 `focus-visible` 复用 Hover 的 `spread` 状态，并增加 `2px rgba(23,105,194,0.35)` 焦点环，外偏移 `2px`。
- 系统开启 `prefers-reduced-motion: reduce` 时：
  - 禁用前后卡位移、旋转、放大、色光、高光和矩阵点动画。
  - 动画时长归零或由全局规则压缩至 `0.01ms`。
  - 保留静态边框、阴影和清晰焦点态，确保可操作性不受影响。

## 10. 研发验收要点

1. Hover 时整卡不位移、不放大，标题和描述不变色。
2. 前卡只做约 `4%` 放大和 `-1.4deg` 微旋转；后卡向右展开 `2px / 3.5deg`。
3. 指针移动时，前后卡反向视差总量应控制在约 `1.35px` 内，不出现明显追手或晃动。
4. 白色高光最高透明度为 `0.35`，不能盖白素材主体。
5. 矩阵点只在局部圆形区域显现，不允许铺满整卡形成噪点墙。
6. 连续快速扫过多个入口时，离开收拢应比进入展开更快。
7. 智能创作显示描述箭头；作品发布不显示。
8. Reduced Motion 模式下无持续闪烁或空间运动。
