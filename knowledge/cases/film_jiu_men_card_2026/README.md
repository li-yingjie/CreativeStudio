# 《九门》影视IP抽卡活动｜黄金案例包 v1

这是一个“制作配置型”案例，不是完整的上线复盘。它适合回答任务规则、卡片等级、资源位、分享文案、素材边界和可复用玩法结构；已收录横竖两张影视IP群像源素材，但仍不具备最终活动页视觉、上线状态和活动效果。

## Agent 调用边界

- 可以说：资料配置了 15 个任务、5 个已确认卡片等级，共 49 张卡；存在抽卡、卡册、赠卡、换卡和分享相关配置。
- 必须带限定：活动时间年份未知且仍待确认；完整分享回流是由多项配置组合得出的推断。
- 必须拒答：没有证据时，不回答“为什么数据好”“最终页面长什么样”“实际曝光/参与/转化多少”。
- 严禁混淆：《永夜星河》图片属于其他活动参考，不是《九门》设计稿。
- 图片调用：优先读取 `assets/optimized/`；需要放大核验细节时再读取 `assets/originals/`。
- 权限：源资料为内部受限内容。本地只保存结构化事实和来源定位，不复制临时鉴权链接、网盘口令或受限附件。

## 人工复核重点

1. 补活动年份并确认起止时间。
2. 补最终上线稿或上线页面快照。
3. 补活动目标、目标人群和核心效果指标。
4. 确认素材命名中出现的 `SF` 是否为历史残留；当前不能把它列为第六档卡片。
5. 补齐视频组、角色、搜索、话题和腾讯小程序路由等执行ID。
