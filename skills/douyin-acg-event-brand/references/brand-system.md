## 视觉语法

1. Hero 拆成平台锁定、独立主 KV、透明艺术字、阶段/会场条和操作层；保持每层可替换。
2. 长页使用连续舞台而非统一白卡：弧形顶边、暖白底板、贴纸标题、票券缺口和局部满版插画承担转场。
3. 一玩法一皮肤：对抗=蓝红分屏；榜单=排行条+双动作；愿望=横向漂移纸条；抽奖=完整机器；任务=低装饰列表。
4. 色彩以暖奶油底、抖音红/珊瑚橙、金黄高光和清亮蓝为主；正文用深酒红，不用纯黑压死节庆感。
5. 主标题和章节标使用图片/矢量锁定；按钮、数字、长文案和状态必须保持真实组件。

## 复杂度门槛

- 至少 6 个业务区块、4 种模块皮肤、7 类素材家族。
- 不能只生成背景图；必须为主 KV、艺术字、章节、内容、角色、奖励与舞台装饰分别建素材槽位。
- 禁止全页同卡片、同圆角、同阴影、同排版模板。
- 装饰层 `pointer-events: none`，编辑模式仍能点选内容组件。

## 生图约束

按“使用场景/画幅 → 舞台构图 → 主体层级 → 色彩材质 → 安全区 → 排除项”组织提示词。使用：

`clean premium ACG campaign illustration, smooth controlled shading, soft directional lighting, broad readable color masses, continuous gradients, crisp silhouettes, restrained microtexture`

明确排除：可见颗粒、斑驳、过锐光晕、脏纹理、混乱高频细节、过量粒子、已有 IP、Logo、水印和烘焙 UI 文字。不要依赖 `--no` 语法。
